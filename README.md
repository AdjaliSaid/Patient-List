# Patients LIST System

A web-based platform to support breast cancer awareness and patient management. This system enables medical professionals and caregivers to securely manage and track patient information.

## 🩺 Features

- Secure patient data management
- Add, edit, delete patients
- Search, filter, and sort by multiple fields
- Real-time updates and validations
- Professional user feedback and error handling

## 👩‍⚕️ Target Users

- Medical professionals
- Caregivers
- Patients involved in breast cancer treatment and monitoring

## 🛠️ Tech Stack

- **Frontend**: React, HTML, CSS
- **Backend**: Node.js
- **IDE**: Visual Studio Code
